# Five-voter path explorer

Extract the ZIP and open index.html in a browser. No network is needed. Choose one leader per path. Each visible bundle includes the leader and the immediate neighbors. The diagram shows the radius-two components of the actual ranking gadget. The score table enumerates each added voter once.

The default A–L, B–R, C–L choice realizes a perfect matching and gives p and g nine votes. Changing A to M gives x₀ ten. Changing only B to L gives y₁ and z₁ ten. The controls also offer endpoint leaders, which cannot add the middle p-voter.

The GIF presents the default selection in 72 frames from a rotating camera. To regenerate it with existing Python and Pillow, run python3 visualization/render.py. Fonts can change the resulting bytes.
